Lecture 11

Neural Networks for Sequences

So far we have looked at two ways to build a neural network: with multilayer perceptrons (MLP), and a convolutional neural network (CNN). MLP's are especially useful for tabular data, that is, where your dataset is a vector of features. In addition, we have seen that CNN's are especially useful for image data. But now, what if our input and/or output data is a sequence? For example, this could used for machine language translation, speech recognition, text classification, or image captioning.

And so, we will look at three different types of tasks:

  1. Vec2Seq (sequence generation from vector input data) - ex. image caption generation
  2. Seq2Vec (sequence classification from sequence input data) - ex. sentiment classification
  3. Seq2Seq (sequence translation from sequence input data) - ex. language translation

The problem with CNN's is that the size of the output will be a fixed and known quanity that is based on the filter/kernel. And so, if you want to generate a sequence, you would often want the sequence to have a length that can vary, and so a CNN is not equipped to control the sequence size on the fly.

To generate sequences of variable length, we first must have a state that keeps track of past sequence information. We then also have a special token called $< \text{EOS}>$ that indicates the end of a sequence. Similarly, we can also have token $< \text{SOS}>$, that indicates the start of a sequence.

Recurrent Neural Networks

And so, below shows a general schematic for a recurrent neural network (RNN), where we have out inputs $x$, our outputs $o$, each indexed by $t$, the time step. We also have a hidden state $h$, which is produced by both the input, and the hidden state from the previous time step.

$$\text{Matrix Shapes:}\;\;\;\;U\;:\;m\times d,\;\;V\;:\;m\times m,\;\;W\;:\;n\times m$$ \begin{align*} h_t & = f\left(V\cdot h_{t-1}+U\cdot x_t+b_h\right) \\ o_t & = g\left(W\cdot h+b_o\right) \end{align*}

Where $b_h$ is some bias term, and $f$ is an activation function ($\tanh$ or $\text{ReLU}$)

Let's motivate this with a quick example. Suppose $f$ is the $\text{ReLU}$ function, $g$ is the identity mapping, and $x_t\in \mathbb{R}^2$, $h_t\in \mathbb{R}^3$, and $o_t\in \mathbb{R}^1$. Let:

$$U=\begin{bmatrix} 1 & 0 \\ 0 & 1 \\ -1 & 0 \end{bmatrix},\;\;\;\;V=\begin{bmatrix} 0 & 1 & 0 \\ 0 & 0 & 1 \\ 1 & 0 & 0 \end{bmatrix},\;\;\;\;W=\begin{bmatrix} 1 & 0 & -1 \end{bmatrix}$$

Assume all bias terms are zero. Assume that at time step $t$, we have:

$$h_{t-1}=\begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix},\;\;\;\; x_t=\begin{bmatrix} 1 \\ 0 \end{bmatrix}$$

What is $h_t$ and $o_t$? Well, we first compute:

\begin{align*} h_t & =\text{ReLU}\left(\begin{bmatrix} 0 & 1 & 0 \\ 0 & 0 & 1 \\ 1 & 0 & 0 \end{bmatrix}\cdot \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix}+\begin{bmatrix} 1 & 0 \\ 0 & 1 \\ -1 & 0 \end{bmatrix}\cdot \begin{bmatrix} 1 \\ 0 \end{bmatrix}\right) \\ & =\text{ReLU}\left(\begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}+\begin{bmatrix} 1 \\ 0 \\ -1 \end{bmatrix}\right) \\ & = \boxed{\begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix}} \end{align*}

And then we find:

$$o_t=W\cdot h_t=\begin{bmatrix} 1 & 0 & -1 \end{bmatrix}\cdot \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix}=\boxed{1}$$

Vec2Seq (Sequence Generation)

Here, we have one vector as input that we feed to all time steps in the hidden layer, and the output $y_{1:T}$ is generated one token at a time. Moreover, at each step we sample from $y_t$ from the hidden state $h_t$, and then feed it back into the model to get $h_{t+1}$. Seq2Vec (Sequence Classification)

Here we want to preduct a single fixed-length output vector given a variable length sequence as input. In this case, we don't have a different output at each time step, instead we have one output at the end after all of our hidden states. A slight variation of this is using what's called a bidirectional RNN, in which you can now use information from furture hidden states, instead of just past hidden states. Here, we have two running RNN's: one that runs from past to future, and one that runs from future to past. And the hidden state we use is simply a concatenation of the two hidden states that run in opposite directions.

We then average out the hidden states, and finally apply a linear transformation to that averaged hidden state to get our final output.

Seq2Seq (Sequence Translation)

Here, we input a sequence and output a sequence, and it comes in two different flavours, aligned, and unaligned. For aligned Seq2Seq, our input and output sequences are of the same size. For this flavour, the RNN is very similar to the Vec2Seq model seen previously, but here the hidden states at time $t$ does not have to depend on the output at time $t-1$. You can even have a bi-directional version for this as well.

In practice, you can make this model more expressive by having a deeper RNN, i.e with more hidden states. So now, each hidden layer has both a time index and a lyer index $h_t^l$.

For unaligned Seq2Seq, the length of the input and output sequences don't necessarily have to be the same. In this case there will be two parts to the RNN: an encoder RNN and a decoder RNN. In the encode section, we take the input sequence and process it with an RNN that converts it to some hidden vectors (via Seq2Vec). Then, these hidden vectors are passed as input into another RNN, the decoder RNN, to produce the final output sequence (via Vec2Seq).

Attention

There are a few limitations of RNN's, namely, is the fact that the past information of a sequence is all stored in the hidden state, stored in its memory. And at some point, this memory will fill up and then we will lose context about what happened in the past. In addition, an RNN processes tokens in a sequence one-by-one, and so you cannot exactly process the entire sequence at the same time, and so the time of processing is proportional to the length of the sequence. Ideally, we would want a way to parallelize the processing of the sequence.

And so, instead of a linear combination of input activations (as in $z=g(Wx)$), the model shoudl dynamically decide (in an input dependent way), which one to use based on how similar the input query vector $q\in \mathbb{R}^q$ is to a set of $m$ keys $K\in \mathbb{R}^{m\times k}$. If $q$ is most similar to key $i$, then we use value $v_i$.

Let's explain more at a high level what this means. We have an example of aligned Seq2Seq processing using the two words below as input. For each of these inputs, we have an embedding or a vector that is associated to each word. Then, for each word, we need to compute a query, found by multiplying the word embedding with the query matrix $W^Q$. In addition, for each word you also need to find the keys and are found by multiplying the embedding word vector by the key matrix $W^K$. Finally, you find value vectors by multiplying the embedding by the value matrix $W^V$.

You then attain a score value by taking the dot product the queries with each key, and then you normalize by dividing by the square root of the dimension of key/query vector. You then take the softmax of these normalize score values. Softmax normalizes the scores so they’re all positive and add up to 1. These final numbers are the attention coefficients. You then scale your value vectors by the attention coefficients.This softmax score determines how much each word will be expressed at this position. Clearly the word at this position will have the highest softmax score, but sometimes it’s useful to attend to another word that is relevant to the current word.

The next step is to multiply each value vector by the softmax score (in preparation to sum them up). The intuition here is to keep intact the values of the word(s) we want to focus on, and drown-out irrelevant words (by multiplying them by tiny numbers like 0.001, for example). Then sum up the weighted value vectors. This produces the output of the self-attention layer at this position (for the first word).

That concludes the self-attention calculation. The resulting vector is one we can send along to the feed-forward neural network. In the actual implementation, however, this calculation is done in matrix form for faster processing.

If this is still not clear, we can go through the math more explicitly. Let $\left\{x_t\in \mathbb{R}^n|t\in \{1,\dots, T\}\right\}$ be an input sequence of length $T$, where each element of the sequence is a vector of dimension $n$. Let $\left\{y_s\in \mathbb{R}^m |s\in \{1,\dots,S\}\right\}$ be the sequence of vectors doing the attending. Then we have:

\begin{align*} \text{Query Vector: } & \;\;q_s=\underbrace{W^Q}_{d\times m} \cdot y_s\in \mathbb{R}^d \\ \text{Key Vector: } & \;\;k_t=\underbrace{W^K}_{d\times n} \cdot x_t\in \mathbb{R}^d \\ \text{Value Vector: } & \;\;v_t=\underbrace{W^V}_{r\times n} \cdot x_t\in \mathbb{R}^r \end{align*}

We want two tokens to attend to each other if their keys and queries align, since their dot product will be a large number and hence a high attention weight to be drawn between this key and query.

The more $q_s$ is aligned with $k_t$, the more the token at time $s$ pays attention to the token at time $t$. The attention paid by the token at time $s$ to the token at time $t$ is shown below. I.e the attention coefficient will be found via:

$$a_{st}=\frac{\exp\left(q_s\cdot k_t/\sqrt{d}\right)}{\sum_{i=1}^T \exp\left(q_s\cdot k_t/\sqrt{d}\right)}$$

As we can see, these coefficients can be indexed as elements within a matrix. An example of such a matrix is shown below, where we are trying to translate a sentence of English to Spanish. Notice similar words have high attention associated to them.

And then finally to get out outputs, we multiply the attention matrix with our value vector:

$$z_s=\sum_{t=1}^T a_{st}v_t$$

To make clear, let us go through a quick example. Suppose we have an input sequence of token vectors shown below. We have a output token vector $y$ shown below as well, and we are interested to see how well does this output token vector attend to the input vectors.

$$x_t=\left\{\begin{bmatrix} 1 \\ 0 \\ 0 \\ 0 \end{bmatrix}, \begin{bmatrix} 0 \\ 1 \\ 0 \\ 0 \end{bmatrix}, \begin{bmatrix} 1 \\ 0 \\ 0 \\ 0 \end{bmatrix}\right\},\;\;\;\;\;\;y=\begin{bmatrix} 1 \\ -1 \\ 0\end{bmatrix}$$

And the weight matrices associated to the keys, values, and queries are:

$$W^K=\mathbb{I}_{4\times 4},\;\;\;\;\;\;\;W^V=\begin{bmatrix} 1 & 0 & 0 & 0 \\ 0 & 1 & 1 & 0 \end{bmatrix},\;\;\;\;\;\;\; W^Q=\begin{bmatrix} 0 & 1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 1 \\ 1 & 0 & -1 \end{bmatrix}$$

And so we compute the key, value, and query vectors as:

\begin{align*} k_t & =\left\{\mathbb{I}_{4\times 4}\begin{bmatrix} 1 \\ 0 \\ 0 \\ 0 \end{bmatrix}, \mathbb{I}_{4\times 4}\begin{bmatrix} 0 \\ 1 \\ 0 \\ 0 \end{bmatrix}, \mathbb{I}_{4\times 4}\begin{bmatrix} 1 \\ 0 \\ 0 \\ 0 \end{bmatrix}\right\}= \left\{\begin{bmatrix} 1 \\ 0 \\ 0 \\ 0 \end{bmatrix}, \begin{bmatrix} 0 \\ 1 \\ 0 \\ 0 \end{bmatrix}, \begin{bmatrix} 1 \\ 0 \\ 0 \\ 0 \end{bmatrix}\right\} \\ v_t & = \left\{W^V\begin{bmatrix} 1 \\ 0 \\ 0 \\ 0 \end{bmatrix}, W^V\begin{bmatrix} 0 \\ 1 \\ 0 \\ 0 \end{bmatrix}, W^v\begin{bmatrix} 1 \\ 0 \\ 0 \\ 0 \end{bmatrix}\right\} = \left\{\begin{bmatrix} 1 \\ 0 \end{bmatrix}, \begin{bmatrix} 0 \\ 1 \end{bmatrix}, \begin{bmatrix} 1 \\ 0 \end{bmatrix}\right\} \\ q & = W^Q y = \begin{bmatrix} -1 \\ 1 \\ 0 \\ 1 \end{bmatrix} \end{align*}

Taking the dot product of the query and key vector and feeding this as input into the softmax function to the attention coefficients (in attention matrix $A$), we get:

$$q\cdot k_t=\begin{bmatrix} -1 & 1 & -1 \end{bmatrix}, \;\;\;\;\;\;\;\;\;\;A=\text{softmax}\left(q\cdot k_t/\sqrt{d}\right)= \frac{\begin{bmatrix} e^{-1/2} & e^{1/2} & e^{-1/2} \end{bmatrix}}{e^{-1/2} + e^{1/2} + e^{-1/2}}$$

Now we compute the product of this with the value vectors to get out outputs:

$$z=\frac{e^{-1/2}\begin{bmatrix} 1 \\ 0\end{bmatrix}+e^{1/2}\begin{bmatrix} 0 \\ 1\end{bmatrix}+e^{-1/2}\begin{bmatrix} 1 \\ 0\end{bmatrix}}{e^{-1/2}+e^{1/2}+e^{-1/2}} =\boxed{\begin{bmatrix} 2e^{-1/2} \\ e^{1/2}\end{bmatrix}/ (2e^{-1/2}+e^{1/2})}$$

Transformers

Transformers are a more modern sequenced neural network that has the ability of attention, and thus has sort of replaced RNN largely. It has the quality of positional encoding, to essential know where the sequence elements are placed relative to each other. This is quite important, since attention is permutation invariant, and hence ignores the input word ordering. To overcome this, we can concatenate the word embeddings with a positional embedding so that the model knows what order the words occur in.

How we do this is a bit strange: suppose that the input representation $\mathbf{X}\in \mathbb{R}^{n\times d}$ contains the $d$-dimensional embeddings for tokens of a sequence. The positional encoding outputs $\mathbf{P}$ using a positional embedding matrix $\mathbf{P}\in \mathbb{R}^{n\times d}$ of the same shape, whose element on the $i^{\text{th}}$ row and the $(2j)^{\text{th}}$ or $(2j+1)^{\text{th}}$ column is:

\begin{align*} p_{i,2j} & = \sin \left(\frac{i}{10000^{2j/d}}\right) \\ p_{i,2j+1} & = \cos\left(\frac{i}{10000^{2j/d}}\right) \end{align*}

In the positional embedding matrix $\mathbf{P}$, rows correspond to positions within a sequence and columns represent different positional encoding dimensions.
